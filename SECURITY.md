# Security policy

## Reporting a vulnerability

For vulnerabilities introduced by this maintained fork or its maintenance
changes, use
[GitHub private vulnerability reporting](https://github.com/vartaxe/ModernDriverManagement/security/advisories/new).
Please include the affected version or commit, reproduction steps, and the
potential impact.

Do not disclose credentials, Configuration Manager data, customer or device
information, or sensitive deployment details in a public issue, discussion, or
pull request. Redact logs and screenshots before sharing them.

If the issue also affects the upstream
[MSEndpointMgr/ModernDriverManagement](https://github.com/MSEndpointMgr/ModernDriverManagement)
project rather than this fork's maintenance changes, report it through the
upstream project's preferred security channel. General product support,
configuration questions, and non-security defects should be reported to the
appropriate project issue tracker or support channel.
